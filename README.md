> A simple command-line number guessing game. Can you crack the code?

---

## About

The computer picks a secret number between `1` and `10` — your job is to guess it. Win or lose, you can keep playing as many rounds as you like!

---

## Getting Started

**1. Make sure Python 3 is installed**
```bash
python --version
```

**2. Clone or download this repo**
```bash
git clone https://github.com/DmytroH2013/Guessing-Game
```

**3. Run the game**
```bash
python number_guesser.py
```

## Features

- 🎯 Random number generated each round
- 🔁 Play again without restarting the script
- 💡 Reveals the answer if you lose
- ⚡ Zero dependencies — just Python

---

## Built With

Pure Python 3 — only the `random` module from the standard library. No installs needed.
